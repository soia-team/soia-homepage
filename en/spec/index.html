Problem

When a home, product, pricing, showcase, and documentation page exist together, readers need to know what understanding problem each one solves—not read the same marketing sentence in six places.

The job of a spec page is to break complex material into reviewable sections: goal, audience, boundary, module, status, evidence, and next step. It does not pretend to be a finished product description when content is not ready.

“Make the information container clear first; then put real, verifiable content inside.”

Page rules

Whatever the final content is, each page follows four checkable expression rules.

01 / SUBJECT

Clear subject

Every page has a reader-facing topic sentence instead of only an internal name.

02 / SCOPE

Clear scope

Facts have an audience, time, premise, and exclusion.

03 / EVIDENCE

Clear basis

When a claim is needed, link to public reviewable material or state that it is still pending.

04 / ACTION

Clear direction

After reading, the primary action points to one sensible next step rather than a random link set.

Replacement order

This is a suggested order for content returning to the site. It is not a promise of timing, pricing, or any external commitment.

01 / FACTS

Confirm facts

Verify every claim, name, price, case, and link is real and public before it is written.

02 / COPY

Write into pages

Write by page responsibility, reduce cross-page repetition, and allow people to understand through navigation.

03 / REVIEW

Review visually

Use desktop and mobile views to check type, whitespace, overflow, links, and reading order.
