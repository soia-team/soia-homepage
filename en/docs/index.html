Replace facts first. Polish expression later.

The site currently carries none of its previous business content. This page only records the order, place, and minimum information unit for content returning to the pages.

01. What remains now

Navigation, heading hierarchy, section proportion, card types, tables, indexes, responsive behavior, and basic interaction remain. Brand, product names, pricing, cases, service copy, customer evidence, and external links are all waiting to be replaced.

  1. Start each page with one verifiable sentence of purpose.
  2. Add the audience, scope, time, and exception.
  3. Only then decide whether it needs imagery, a case, a download, or a form.

02. Suggested replacement order

Start from the home page, but do not write only the home page. Home, product, pricing, showcase, docs, and spec should draw from one set of facts and terms.

01 / HOME

One position

People know who this is, who it is for, what value it creates, and where to begin.

02 / PRODUCT

Product facts

Name, use, status, boundary, evidence, and a way to read detail.

03 / PRICE

Price facts

Price, effective date, inclusions, limits, conditions, and after-sales path.

04 / PROOF

Evidence material

Public cases, screenshots, links, versions, or independently reviewable deliverables.

03. Keep writing short first

Headlines state outcomes; body copy supplies boundaries. Use real nouns, numbers, dates, and exclusions. Without evidence, keep a placeholder rather than make a vague promise.

Page theme: what understanding problem does this page solve? | Audience: who needs it? | Fact source: what supports this statement? | Next step: what is the single sensible action?

04. Each page has an information contract

An information contract is not a business workflow. It only defines the minimum a page must make clear, so content does not repeat or contradict itself when it comes back.

TITLE

Clear subject

Define the page with a reader-facing outcome or question, never an internal code name.

CONTEXT

Clear scope

Name the audience, prerequisite, time, or version so a claim does not float without a boundary.

EVIDENCE

Clear basis

Where needed, link to material that is public and independently reviewable.

ACTION

Clear next step

Keep one primary action per page; everything else is supporting reference.

05. Add assets last

Images, illustrations, video, and customer material enter only after copyright, permission, brand, and privacy boundaries are confirmed. When real assets are absent, neutral CSS artwork and whitespace are better than borrowing someone else’s screenshots.

The geometric pieces in this prototype are neutral CSS placeholders, not final brand assets.
