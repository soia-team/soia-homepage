THE NAME

SOIA stands for four commitments.

SSystem
Facts, rules, and state have a durable home.
OOrchestration
Roles, Skills, and tools work together.
IIntelligence
AI assists understanding, generation, and judgment.
AAssurance
Boundaries, approval, and evidence protect outcomes.

OUR PRINCIPLES

Four rules shape every surface.

When speed conflicts with authorization, data boundaries, or verifiability, the boundary wins.

LOCAL-FIRST

Keep data where it belongs

Using an Agent should not require moving every file into a new center.

PROVIDER-NEUTRAL

Separate capability from model

Keep the core method portable across hosts and providers where practical.

HUMAN-CONTROLLED

People own high-risk decisions

Publishing, deletion, payment, and access changes require explicit approval.

EVIDENCE-BACKED

Let artifacts prove status

Source, tests, receipts, and versions carry more weight than capability slogans.

OPEN / PROPRIETARY

Open the reusable method.
Protect owned workflows.

Openness does not require users to publish their data. Shared capability and proprietary context remain separate.

OPEN BY DEFAULT

Reusable capability

  • General-purpose Skills and methods
  • Public plugin manifests and versions
  • Templates without client facts
  • Public status, releases, and security channels

PROTECTED BY DESIGN

Owned context

  • Client files and internal SOPs
  • Passwords, tokens, cookies, and sessions
  • Unreleased code and business data
  • Restricted templates and decisions
