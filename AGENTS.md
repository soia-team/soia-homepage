# AGENTS.md — SOIA Homepage

## Project rules

- This repository contains the public SOIA brand and product website.
- Public pages explain user outcomes, available products, evidence, and ways to begin.
- Internal pricing tests, revenue plans, lead scoring, private repository details,
  customer material, credentials, and operational task boards never belong here.
- Label claims as Available, Preview, or Roadmap and link to public evidence.
- Codex, Claude Code, and WorkBuddy are host or agent environments, not models.
- Use the shared design system in `assets/styles.css` on every route.
- Do not copy third-party code, wording, branding, screenshots, or visual assets.
- Preserve keyboard navigation, reduced-motion behavior, responsive layout, and semantic HTML.
- Run `python3 scripts/validate_site.py` before publishing.
- Confirm before changing repository visibility.
