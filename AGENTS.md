# AGENTS.md — SOIA Homepage

## Project rules

- This repository is the public source of the SOIA project website.
- The production artifact is static HTML, CSS, and JavaScript. Do not add a framework or runtime dependency without a demonstrated need.
- Keep public claims tied to `docs/product/commercialization-plan.md`; label unverified or future capabilities as pilot or roadmap.
- Never publish credentials, customer material, private repository details, direct payment identifiers, or personal contact details.
- Do not imply that Codex, Claude Code, or WorkBuddy are models. They are host or agent environments.
- GitHub Pages is a public project preview, not a checkout, credential-entry, or sensitive transaction surface.
- Preserve keyboard navigation, reduced-motion behavior, responsive layout, and semantic HTML.
- Run `python3 scripts/validate_site.py` before publishing.
- Confirm before destructive actions or changing either GitHub repository's visibility.
