# Public content principles

The public site answers four questions:

1. What problem does SOIA solve?
2. What can a visitor use today?
3. What evidence supports each claim?
4. What is the safest next step?

Public pages may describe available open-source capabilities, product status,
course outcomes, service deliverables, security boundaries, and public
repositories.

Internal revenue targets, price experiments, channel strategy, lead scoring,
customer notes, private repository structures, credentials, and delivery task
boards stay outside this repository.
