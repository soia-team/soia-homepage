# SOIA commercialization plan

Snapshot date: 2026-08-01

## Positioning

SOIA does not sell prompts. It turns reusable Agent Skills into installable, composable, testable, and maintainable delivery systems across Codex, Claude Code, and WorkBuddy.

## Capability status

| Layer | Status | Reader-facing promise |
|---|---|---|
| Open atomic Skills | Available | Public source, documented scope, installation path, and per-Skill host status |
| Domain plugins | Available | Eight public domain plugins package related capabilities |
| Multi-Skill workflows | Pilot | Several Skills combined around one bounded result and acceptance receipt |
| WorkBuddy experts | Available for implementation | Role plus workflow plus selected Skills; installation and tuning remain a service |
| Custom experts | Pilot service | Customer material becomes a private, bounded expert or expert team |
| Private plugin library | Roadmap | Versioned commercial repositories, updates, support, and entitlement operations |
| Content acquisition system | Pilot | Source monitoring, archiving, opinion distillation, drafting, and channel adaptation; no traffic guarantee |

## Product ladder

1. Open Skills — free.
2. First Run — pilot from CNY 699.
3. Workflow Sprint — from CNY 1,999.
4. Custom Expert — from CNY 5,999 after scoping.
5. Private Plugin Library — future annual access to new versions and support; downloaded versions remain usable according to the commercial license.
6. Team Pilot — one workflow, one team, one acceptance plan; scoped separately.

Prices are validation hypotheses, not established market prices. They must be revised from delivery time, rework, support load, conversion, and renewal evidence.

## Channel roles

- GitHub and SkillHub: open-source discovery, auditability, installation, and technical trust.
- Xiaohongshu: result demonstrations and demand discovery; not a virtual-goods checkout.
- WeChat Official Account: long-form trust and official routing into Knowledge Planet.
- Knowledge Planet: first-stage RMB membership, community, files, updates, questions, and renewal.
- Feishu AI Knowledge Base: later premium searchable knowledge product and AI Q&A layer.
- Private GitHub repositories: versioned delivery and future updates, not payment or DRM.

## Commercial safety boundaries

- Do not promise traffic, revenue, universal host compatibility, or automatic publishing.
- Do not accept passwords, tokens, cookies, or customer secrets in intake forms or public issues.
- One commercial SKU should map to one private repository; one customer-specific overlay should map to one customer repository.
- Access removal stops future updates but cannot revoke local clones or installed caches.
- Every commercial product needs a clear license, third-party notices, versioning, checksums, rollback, and acceptance tests.
