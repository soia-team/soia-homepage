- Purpose: Explain SOIA's open Skills, productized workflows, plugins, WorkBuddy experts, implementation services, and future private product library.
- Owner: `soia-team`
- Architecture: Dependency-free static site in the public `soia-team.github.io` repository. Planning notes contain no customer or commercial secrets.
- Public URL: `https://soia-team.github.io/`
- Migration: point the filed domestic domain at SOIA's own server when ICP filing is complete; GitHub Pages remains the public project mirror.
- Primary public source: `https://github.com/soia-team/soia-open-skills`

## Delivery model

1. Open Skills and public domain plugins establish proof and discovery.
2. Productized workflows and First Run services deliver bounded outcomes.
3. WorkBuddy experts and custom experts package repeatable roles and workflows.
4. A private plugin library may later provide versioned commercial products and updates.
5. Knowledge Planet, WeChat Official Account, Xiaohongshu, Feishu AI Knowledge Base, GitHub, and SkillHub each serve a distinct acquisition, payment, community, or delivery role.
