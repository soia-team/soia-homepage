# Kanvis reference audit

Snapshot: `Kanvis-chen/kanvis-homepage@230f062`, reviewed 2026-08-01.

## What SOIA learns from it

- A dependency-free static site is enough for a clear first release.
- Free open-source capabilities can lead into higher-value implementation,
  course, community, and enterprise offers.
- Product status labels and explicit execution boundaries improve trust.
- A public project page should show evidence before asking for a commercial
  conversation.

## What SOIA does not copy

The Kanvis repository is public but has no declared `LICENSE` file or detected
GitHub license. Default copyright therefore applies. SOIA does not copy its
HTML, CSS, JavaScript, page wording, visual system, brand names, author material,
screenshots, QR codes, video, or other assets.

The SOIA site has its own information architecture, copy, visual design, code,
capability model, status model, and commercial boundaries.
