先替换事实，后润色表达。

站点目前不携带原有的业务内容。这份文档只说明内容重新进入页面时的顺序、位置和最小信息单位。

01. 现在保留什么

保留导航、标题层级、区块比例、卡片类型、表格、目录、响应式行为和基础互动。品牌、产品名称、价格、案例、服务说明、客户证据和外部链接均处于待替换状态。

  1. 先用可核实的一句话给每页定主题。
  2. 再补充对象、范围、时间和例外条件。
  3. 最后决定是否需要图片、案例、下载或表单。

02. 建议的替换顺序

从首页开始，但不要只写首页。首页、产品、价格、展示、文档和规格页应共享一套事实来源与术语。

01 / HOME

一句定位

用户知道这里是谁、为谁提供什么价值，以及第一步可以去哪里。

02 / PRODUCT

产品事实

名称、用途、状态、使用边界、证据和详情入口。

03 / PRICE

价格事实

价格、有效期、包含项、限制、适用条件与售后方式。

04 / PROOF

证据材料

可公开的案例、截图、链接、版本或可复核的交付物。

03. 写作先保持简短

标题说结果，正文补边界。使用真实名词、真实数字、真实时间和明确的不包含项；没有证据时宁可保留占位，也不要写成模糊承诺。

页面主题：这一页解决什么理解问题？｜适用对象：谁需要读它？｜事实来源：这句话由什么支持？｜下一步：读完后唯一合理的行动是什么？

04. 每种页面都有信息契约

信息契约不是业务流程；它只定义一个页面最低限度应说清楚什么，避免内容重新进站后互相重复或彼此矛盾。

TITLE

主题清楚

用一个面向读者的结果或问题定义页面，而不是内部代号。

CONTEXT

范围清楚

写明适用对象、前提、时间或版本，避免没有边界的主张。

EVIDENCE

依据清楚

需要时链接到能公开访问并独立复核的来源。

ACTION

下一步清楚

每页保留一个主行动，其他链接作为辅助参考。

05. 素材最后进入

图片、插图、视频和客户材料应在版权、授权、品牌和隐私边界确认后再放入。没有真实素材时，使用中性 CSS 图形和留白比借用他人的截图更合适。

本原型中的几何图形均为 CSS 生成的中性占位，不代表最终品牌资产。
