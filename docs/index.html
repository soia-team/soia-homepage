从一个公开 Skill 开始，
跑出一条可复核路径。

这份文档讲清楚 SOIA 能力如何被发现、安装、组合和验收。它只说明公开能力，不要求你提交密码、Token、Cookie 或客户资料。

01 · 从哪里开始02 · 安装方式03 · 四层边界04 · 证据与交接

01 / START

先按结果找能力，不必先背名字。

进入开放生态，按能力域或任务关键词浏览。每个 Skill 详情页都有一句话摘要、输入与输出、安装入口、安全边界和公共源码链接。

  1. 写下一个重复任务的结果，而不是一个工具名。
  2. 在能力域目录中找到最小可用 Skill。
  3. 先看公开说明，再决定是否安装整个领域插件。

02 / INSTALL

三种入口，对应三种使用深度。

公开目录同时面向 Claude Code、Codex 和 WorkBuddy。命令以领域插件为单位，单 Skill 入口适合快速试用。

claude plugin marketplace add soia-team/soia-open-skills
claude plugin install soia-meta@soia

codex plugin marketplace add soia-team/soia-open-skills
codex plugin add soia-meta@soia

安装后先运行一个低风险、可撤回的任务；涉及发布、付款、删除、权限或外部写入时，保留人工确认。

03 / BOUNDARY

四层模型，把能力和资料分开。

L1 · SOIA

公共入口

品牌、导航、文档和产品说明，告诉你从哪里开始。

L2 · OPEN

开放生态

通用 Skills、公开插件、源码、许可证和版本证据。

L3 · DOMAIN

能力域

知识、环境、工程、内容、设计、协作和教育等领域目录。

L4 · DELIVERY

交付形态

Skill、Workflow、Plugin、Expert 或经授权的私有适配。

04 / EVIDENCE

每一次运行，都应该留下能交接的回执。

公开能力的事实真源是对应 GitHub 仓库和规范文档。运行结束后至少记录输入、输出、文件变化、验证结果、已知限制和下一步。

  • 公开 Skill 总仓 ↗：插件、manifest 和索引。
  • 知识与内容能力仓 ↗：归档、提炼和内容转换。
  • 涉及私有资料时，使用服务与合作页面确认范围；公共仓库不承载授权资料。
