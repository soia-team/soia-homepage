这个 Skill 能做什么

一个职责聚焦、边界可见的能力。

AI 项目指令与配置设计顾问，提供诊断、起草和改写建议

  • 从自然语言目标和最小必要输入开始，不要求先记住技能名。
  • 只有意图命中时才载入公开指令正文，避免把整个技能库塞进上下文。
  • 执行结束后汇总产物、检查、阻塞项，以及仍需用户决定的动作。

INPUT

PROCESS

受边界控制的执行

安装

可以安装整个领域，也可以只装这一个 Skill。

Claude Code 领域插件

claude plugin marketplace add soia-team/soia-open-skills && claude plugin install soia-dev@soia

Codex 领域插件

codex plugin marketplace add soia-team/soia-open-skills && codex plugin add soia-dev@soia

单 Skill 安装

npx skills add soia-team/soia-open-dev-skills -g -a '*' -s soia-dev-agent-md-advisor -y

WorkBuddy 可让 Agent 安装对应领域 Expert，重启桌面客户端后再做一次可见性与调用验证。

安全与证据

指令可以公开，你的数据不需要公开。

密码、Token、Cookie、客户文件和受限制业务资料不得进入公共 Issue 或仓库。删除、发布、付款、外部写入和权限变更等高风险动作必须获得明确授权。
