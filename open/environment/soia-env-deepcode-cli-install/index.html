01 / 用途

一个聚焦的职责。

为小白安装、配置与授权更新开源 Deep Code Agent CLI（lessweb/deepcode-cli）

自然语言触发「请使用 soia-env-deepcode-cli-install 完成这个任务。」
  • 从自然语言结果与最小必要的授权输入开始。
  • 只有意图命中时，才加载规范 Skill 指令。
  • 以产物、检查、阻塞项和仍归用户决定的事项收尾。

02 / 交付契约

一次完整运行应该包含什么。

01

清楚输入

有权使用的文件、URL、仓库、工作区或明确目标。

02

有界执行

最小可靠步骤、必要预览，以及风险上升处的批准门。

03

可复核回执

文件变化、生成产物、验证结果、已知限制和下一步。
