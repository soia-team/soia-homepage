HOST MATRIX

三种宿主，
三种清晰装载方式。

Claude Code、Codex 与 WorkBuddy 是宿主环境，不是模型名称。每个宿主的安装和验证结果分别记录。

宿主装载单位公开入口使用边界
Claude Code 领域 Plugin Marketplace + plugin install 按领域启停；技能正文仅在命中时加载。
Codex 领域 Plugin Marketplace + plugin add 从同一公开仓安装，兼容性按插件版本验证。
WorkBuddy 角色化 Expert 公开安装脚本 Skill 与 Expert 分开验证；桌面端入口由角色承载。
