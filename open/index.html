WORKBENCH / 专家入口

把公开能力，
装进你的工作环境。

SOIA 不把网页本身包装成云端执行器。Workbench、Plugin 和 Expert 负责把公开能力装进本地宿主；真实资料和高风险动作仍由你控制。

01 / CLAUDE CODE

按需加载 Skill

从公开仓库安装，按任务触发，保留源码和版本证据。

02 / CODEX

组合多个能力

把 Skills 连接成工作流，写清输入、交接、批准点和验收。

03 / WORKBUDDY

进入角色化 Expert

将角色、知识、工具和推荐任务组织成可召唤的专家入口。

HOST MATRIX

三种宿主，
三种清晰装载方式。

Claude Code、Codex 与 WorkBuddy 是宿主环境，不是模型名称。每个宿主的安装和验证结果分别记录。

宿主装载单位公开入口使用边界
Claude Code 领域 Plugin Marketplace + plugin install 按领域启停；技能正文仅在命中时加载。
Codex 领域 Plugin Marketplace + plugin add 从同一公开仓安装，兼容性按插件版本验证。
WorkBuddy 角色化 Expert 公开安装脚本 Skill 与 Expert 分开验证；桌面端入口由角色承载。
